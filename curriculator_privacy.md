# Política de Privacidade para o Curriculator Free

**Última atualização:** 27 de Setembro de 2025

A sua privacidade é a nossa maior prioridade. Esta Política de Privacidade explica como o aplicativo Curriculator Free ("nós", "nosso") lida com suas informações.

## 1. Nenhum Dado é Coletado ou Enviado

O Curriculator Free foi projetado com a filosofia "privacidade em primeiro lugar". O aplicativo funciona **100% offline** no seu computador.

-   **Nenhuma Coleta de Dados Pessoais:** Nós não coletamos, armazenamos, usamos ou compartilhamos nenhuma informação pessoal, dados de currículo, chaves de API ou qualquer outro tipo de dado que você insere no aplicativo.
-   **Nenhum Envio para Servidores:** Nenhuma informação inserida no Curriculator Free é enviada para nossos servidores ou para servidores de terceiros. Tudo o que você cria fica exclusivamente no seu dispositivo.

## 2. Armazenamento Local e Seguro

Todas as informações que você adiciona ao Curriculator Free (dados pessoais, experiências, versões de currículo, etc.) são salvas em um banco de dados local (Isar) diretamente no seu computador. O acesso a esses dados é restrito ao seu dispositivo e ao seu perfil de usuário no sistema operacional.

## 3. Funcionalidade de Inteligência Artificial (IA) Opcional

O Curriculator Free oferece recursos opcionais de otimização e tradução de currículos que utilizam a API do Google Gemini. O uso desta funcionalidade está sujeito aos seguintes termos:

-   **Chave de API Própria:** Para usar os recursos de IA, você deve fornecer sua própria chave de API pessoal e gratuita do Google AI Studio. O Curriculator Free não fornece essa chave.
-   **Envio de Dados para a Google:** Ao utilizar uma funcionalidade de IA, os dados estritamente necessários para a tarefa (como o texto do seu currículo e a descrição de uma vaga) são enviados diretamente do seu computador para os servidores da Google para processamento. Esta comunicação ocorre sob os termos da [Política de Privacidade da Google](https://policies.google.com/privacy).
-   **Nenhum Armazenamento Intermediário:** O Curriculator Free atua apenas como um intermediário para a chamada de API. Nós não armazenamos, registramos ou temos acesso às suas interações com a API do Google.

## 4. Transparência e Código Aberto

Acreditamos no poder da transparência. O uso de tecnologias de código aberto, como Flutter e Isar, garante que não há mecanismos ocultos de coleta de dados no aplicativo.

## 5. Contato

Se você tiver alguma dúvida sobre esta Política de Privacidade, entre em contato conosco através do nosso repositório no GitHub ou outros canais de contato listados no aplicativo.
